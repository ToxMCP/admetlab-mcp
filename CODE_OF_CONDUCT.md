# Code of Conduct

## Our standards

This project is committed to a respectful, harassment-free community for everyone.

Examples of expected behavior:

- Be respectful and constructive in feedback.
- Focus criticism on ideas and implementation details.
- Assume good intent and ask clarifying questions.

Examples of unacceptable behavior:

- Harassment, hate speech, or discriminatory language.
- Trolling, personal attacks, or intimidation.
- Publishing private information without consent.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues, pull requests, and discussions.
- Project-related chat or communication channels.

## Reporting and enforcement

If you experience or witness unacceptable behavior, report it to repository maintainers.

Preferred reporting path:

1. Open a private maintainer contact on GitHub.
2. If private contact is unavailable, open an issue requesting maintainer follow-up.

Maintainers will review reports promptly and may take actions including warning, temporary ban, or permanent removal from project spaces.
